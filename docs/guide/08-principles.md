# 8. Principles

The principle skills are small on purpose. They cover scope, data modeling, premise attacks, domain boundaries, types, idempotence, concurrency ownership, root-cause fixes, behavioral tests, runtime proof, context preservation, and encoding recurring lessons into structure.

Load a principle when it changes a decision. If it does not change a decision, citing it is noise. Explicit user constraints outrank stylistic preference; state the tradeoff rather than silently overriding the request.
